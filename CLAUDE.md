# Минимум v2 — конституция

Личный PWA-трекер ежедневного минимума владельца (БАО). Прод — GitHub Pages `https://xbaox.github.io/minimum/` из `main`.
Методология — «Атомные привычки» Джеймса Клира. Слова, по которым проверяется каждое решение: **простота, стабильность,
минимализм, красочность, дисциплина, самоконтроль, окружающая среда, привычки, 1% лучше каждый день.**
Старое приложение (v1) — в git под тегом `v1-final`; его код и конституцию не изучать и не возвращать.

## Принципы

1. **Минимум — пол, а не план дня.** Одинаков каждый день: школьные дни A и B, выходные, каникулы, худший день. У пунктов нет часов, расписаний и дней недели. План дня — в iOS «Напоминаниях», не здесь.
2. **Мало и конкретно.** Каждый пункт выполним в плохой день. Подпись пункта — «когда / после чего» (связка привычек), без лозунгов.
3. **Отметка — одно касание.** На «Сегодня» нет форм.
4. **Не пропускай дважды.** Один незакрытый день серию не рвёт, два подряд — серия с нуля.
5. **1% в неделю.** Одно улучшение, выбирается на итогах недели. Приложение само ничего не повышает: только предлагает, решает владелец.
6. **Сон — главная цель сейчас.** Цель отбоя двигается шагами только по решению владельца на итогах недели.
7. **Всё правит владелец** в «Настройках»: пункты, подписи, эмодзи, цвета, порядок, недельные счётчики, цели сна.
8. **Против раздувания.** Новая сущность, экран или настройка — только по явному решению владельца. При попытке добавить 11-й ежедневный пункт приложение переспрашивает.
9. **Красочно, но спокойно.** Цвет несёт смысл (пункт, прогресс, сон). Без звуков, пушей, мигания и стыда. Тексты владельца никогда не обрезаются многоточием — переносятся.
10. **Данные только на устройстве:** localStorage + зеркало в IndexedDB, экспорт/импорт JSON.

**Не делать никогда:** пуш-уведомления, аккаунты и синхронизация, очки/уровни/ранги, режимы, маски дней, блоки с часами,
порог зачёта дня, таймеры учёбы, экран заметок, журнал упражнений, туториал-онбординг, фреймворки, сборщики,
рантайм-зависимости. Не трогать чужие ключи, базы и кэши на общем домене `xbaox.github.io` (там живут english-summer,
oborot, study и другие PWA владельца).

**Правило против раздувания для исполнителя.** Делай ровно то, что просит задача. Идея сверх задачи — в отчёт
(«Идеи»), не в код. Новый экран, сущность, настройка, поле модели, зависимость — только после явного «да» владельца.
Дыру в задаче закрывай самым простым решением и пиши в отчёт («Решения вне задачи»). Ориентир веса: весь JS ≈ 60 КБ.

## Карта файлов

| файл | что внутри |
|---|---|
| `index.html` | оболочка, мета для iOS standalone, запуск `boot()` |
| `styles.css` | все токены в `:root` (цвета, кегли, радиусы, отступы, длительности), светлая/тёмная тема |
| `app.js` | интерфейс: Сегодня · Прогресс · Настройки, лист «Итоги недели», обновление воркера; экспорт `boot()` |
| `domain.js` | чистая логика без DOM: даты, план, статусы, серия, сон, предложение, итоги, нормализация |
| `store.js` | localStorage + зеркало IndexedDB, стирание v1, экспорт/импорт |
| `sw.js` | кэш `VERSION`, протокол сообщений, чистка своих кэшей |
| `manifest.json`, `icon-*.png` | PWA; иконки перерисует дизайн-этап |
| `tests/*.test.js` | `domain`, `store`, `sw`, `dom` (jsdom), `style` (контраст, токены, без многоточия) |

Ванильный JS, ES-модули, без сборки. Только относительные пути `./`. Dev-зависимости: `jsdom`, `fake-indexeddb`.

## Модель данных

Ключ localStorage — `minimum.v2`. Зеркало — IndexedDB `minimum-v2`, store `kv`, ключ `state` (запись ~300 мс после изменения).

```json
{
  "schema": 1, "createdAt": "2026-09-30", "since": "2026-07-20",
  "items":  [{ "id": "uuid", "emoji": "🌅", "name": "…", "note": "…", "color": "amber",
               "beforeBed": null, "addedAt": "YYYY-MM-DD", "archivedAt": null }],
  "weekly": [{ "id": "uuid", "emoji": "🏋️", "name": "Тренировка", "note": "…", "color": "green",
               "perWeek": 3, "addedAt": "YYYY-MM-DD", "archivedAt": null }],
  "days": { "YYYY-MM-DD": { "plan": ["uuid"], "done": ["uuid"] } },
  "weekMarks": { "uuid": ["YYYY-MM-DD"] },
  "sleep": { "goalBed": "23:30", "goalWake": "07:30",
             "targets": [{ "from": "YYYY-MM-DD", "bed": "01:00" }],
             "nights": { "YYYY-MM-DD(утро)": { "bed": "01:00", "wake": "07:30" } } },
  "reviews": { "YYYY-MM-DD(пн)": { "closedAt": "ISO", "good": "", "bad": "", "learned": "", "notesDone": false,
               "improvement": "", "sleep": { "from": "01:00", "to": "00:30", "choice": "earlier30|earlier15|keep|later15" } } },
  "ui": { "welcomeSeen": false }
}
```

`normalize()` (он же `migrate()`): битые поля → значения по умолчанию, неизвестные выбрасываются. Новая версия схемы —
`schema` + ветка в `migrate()`, только по решению владельца. Правки пунктов не переписывают прошлое: прошлые дни живут
своими снимками плана, название показывается по id. Пункты не удаляются — только `archivedAt`.

## Правила расчёта (`domain.js`)

- **Логический день:** граница 04:00 местного (константа). Арифметика дат — календарная по `YYYY-MM-DD` через `Date.UTC`; переходы времени не сдвигают дни. Открытое приложение перерисовывается на границе (таймер + `visibilitychange`).
- **Неделя** — пн–вс.
- **План дня:** `days[D].plan` — снимок активных пунктов. Сегодня снимок живой. Вчера можно доотмечать до конца сегодняшнего логического дня (нет записи — создаётся с активными пунктами). Раньше вчера — заморожено. День без записи для статистики восстанавливается по `addedAt`/`archivedAt`.
- **Статус:** `closed` — план не пуст и весь в `done`; `pending` — сегодня и не закрыт; `miss` — прошедший день ≥ `createdAt` не закрыт или без записи; `none` — до `createdAt`, пустой план, или незакрытый день посева.
- **Серия:** назад от сегодня (если закрыт) или от вчера: `closed` → +1 и сброс пропусков; `miss` → пропуск, на втором подряд — стоп; `none` — мимо. З З П З → 3; З П П З → 1. **Рекорд** — максимум тем же правилом.
- **Недельный счётчик:** `weekMarks[id]` — даты, не больше одной в день; счёт недели — с пн по вс.
- **Сон:** ночь — под датой утра. `norm(HH:MM)` = минуты, при часе < 12 плюс 1440. `targetFor(date)` — последний `targets` с `from ≤ date`. «В цель» — `bed` есть и `norm(bed) ≤ norm(targetFor)`. Длительность — `(wake + 1440) − norm(bed)`. Дедлайн пункта с `beforeBed` — `шаг − beforeBed` через полночь.
- **Предложение на итогах недели W:** утра E — с max(пн W, `createdAt` + 1) по min(вс W, сегодня); r = K / |E|. r ≥ 0.7 → рекомендовано «−30» (ещё «−15», «Оставить»); 0.4 ≤ r < 0.7 → «Оставить» (ещё «−15»); r < 0.4 → «Оставить» (ещё «+15»); |E| = 0 → только «Оставить». Не раньше цели отбоя, не позже 03:00; одинаковое время — одна кнопка. Выбор обязателен; новый шаг — в `targets` с `from` = завтра. Ручная правка шага — так же.
- **Итоги:** в воскресенье — баннер этой недели; пн–сб — баннер незакрытой прошлой. Строка «1% недели» — всю неделю после закрытой.

## Переход с v1 (v50) — не ломать

- При каждом старте `purgeLegacy()`: удалить ключи localStorage с префиксом `minimum:` и базу IndexedDB `minimum`. **Старые ключи и базу не возвращать никогда**, импорт старого файла — отказ.
- Воркер понимает протокол старой страницы: `{type:'version'}` + порт → `{version}` в порт; `{type:'skipWaiting'}` → `self.skipWaiting()`. Формат `VERSION` строго `minimum-vN` (страница v50 читает `^minimum-(v\d+)$`).
- `install` кладёт `ASSETS` с `cache: 'reload'` и ждёт (без автоматического `skipWaiting`). `activate` удаляет **только** кэши с префиксом `minimum-`, кроме текущего, и делает `clients.claim()`. **Чужие кэши не трогать** — Cache Storage общий на домен.
- Страница: регистрация `./sw.js` с `updateViaCache: 'none'`; есть ожидающий воркер при живом контроллере → полоса «Доступна новая версия · Обновить»; перезагрузка после `controllerchange` — только если владелец нажал. Проверка — при запуске, при возвращении из фона (не чаще раза в 10 минут) и кнопкой в Настройках.

## Интерфейс — неизменяемые правила

- iOS Safari standalone; основной экран 428×926, проверять и 390×844. `viewport-fit=cover`, safe-area, `100dvh`, цели ≥ 44 px, поля ≥ 16 px, строки пунктов ≥ 56 px, `touch-action: manipulation`, свой `:active`.
- Все цвета, радиусы, отступы, кегли, длительности — только токены `:root` (сторожит `tests/style.test.js`). Текст ≥ 4.5:1, галочка на заливке ≥ 3:1 (белая или почти чёрная).
- Движение — только `transform`/`opacity`, 180–240 мс ease-out; праздник закрытия дня ≤ 800 мс; `prefers-reduced-motion` отключает всё.
- `text-overflow: ellipsis` запрещён. Пользовательский текст — только текстовыми узлами.
- Графики — свой SVG, без библиотек. Язык интерфейса — русский.

## Проверка и релиз

- `npm test` (`node --test tests/*.test.js`; в каждом файле первым делом `process.env.TZ = 'America/Toronto'`). CI — `.github/workflows/test.yml`, держать зелёным.
- Глазами: `.claude/launch.json` → встроенный браузер, 428×926 и 390×844, светлая и тёмная, консоль без ошибок. Демо-данные — только в превью, не в коде. Перед проверкой снять воркер и кэши, иначе cache-first покажет старые файлы.
- Релиз: поднять `VERSION` в `sw.js` (`minimum-vN`, N растёт), все тесты зелёные, коммит «Релиз minimum-vN», **push в `main` — только по слову владельца «релиз»**, затем проверить, что `https://xbaox.github.io/minimum/sw.js` отдаёт новую версию.
- Push только с noreply-адреса GitHub (`233407916+xbaox@users.noreply.github.com`) — приватный адрес блокируется.
- Коммиты — по-русски.

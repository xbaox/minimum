# Минимум — конституция (v3: живой интерфейс)

Личный PWA-трекер ежедневного минимума владельца (БАО). Прод — GitHub Pages `https://xbaox.github.io/minimum/` из `main`.
Методология — «Атомные привычки» Джеймса Клира. Слова, по которым проверяется каждое решение: **простота, стабильность,
минимализм, красочность, дисциплина, самоконтроль, окружающая среда, привычки, 1% лучше каждый день.**
Старое приложение (v1) — в git под тегом `v1-final`; его код и конституцию не изучать и не возвращать.

## Принципы

1. **Минимум — пол, а не план дня.** Одинаков каждый день: школьные дни A и B, выходные, каникулы, худший день. У пунктов нет часов, расписаний и дней недели. План дня — в iOS «Напоминаниях», не здесь.
2. **Мало и конкретно.** Каждый пункт выполним в плохой день. Подпись пункта — «когда / после чего» (связка привычек), без лозунгов.
3. **Отметка — одно касание.** На «Сегодня» нет форм.
4. **Не пропускай дважды.** Один незакрытый день серию не рвёт, два подряд — серия с нуля.
5. **1% в неделю.** Одно улучшение, выбирается на итогах недели. Приложение само ничего не повышает: только предлагает, решает владелец.
6. **Сон — главная цель сейчас.** Цель отбоя двигается шагами только по решению владельца на итогах недели.
7. **Всё правит владелец** в «Настройках»: пункты, подписи, значки, цвета, порядок, недельные счётчики, цели сна.
8. **Против раздувания.** Новая сущность, экран или настройка — только по явному решению владельца. При попытке добавить 11-й ежедневный пункт приложение переспрашивает.
9. **Красочно, но спокойно.** Цвет несёт смысл (пункт, прогресс, сон). Без звуков, пушей, мигания и стыда. Тексты владельца никогда не обрезаются многоточием — переносятся.
10. **Данные только на устройстве:** localStorage + зеркало в IndexedDB, экспорт/импорт JSON. Единственное исключение —
    «Друзья» (v55, решение владельца): взаимно принятым друзьям уходит **снимок** прогресса в Supabase. Источник истины —
    телефон; приложение целиком работает без сети; облако ничего не пишет в отметки.

**Не делать никогда:** пуш-уведомления, аккаунты с почтой и паролем, синхронизация своих данных между устройствами,
очки/уровни/звания, рейтинги и места — кроме «Гонки недели» друзей (v56, решение владельца), режимы, маски дней, блоки с часами,
порог зачёта дня, таймеры учёбы, экран заметок, журнал упражнений, туториал-онбординг, фреймворки, сборщики,
рантайм-зависимости. Не трогать чужие ключи, базы и кэши на общем домене `xbaox.github.io` (там живут english-summer,
oborot, study и другие PWA владельца).

**Правило против раздувания для исполнителя.** Делай ровно то, что просит задача. Идея сверх задачи — в отчёт
(«Идеи»), не в код. Новый экран, сущность, настройка, поле модели, зависимость — только после явного «да» владельца.
Дыру в задаче закрывай самым простым решением и пиши в отчёт («Решения вне задачи»). Ориентир веса: весь JS ≈ 224 КБ сырых / 68 КБ gzip (v56, с друзьями и гонкой: `app.js` — 126 / 36, `cloud.js` — 18 / 6, `share.js` — 14 / 5, движок `dom.js` — 23 / 8), CSS ≈ 58 / 13.

## Модель данных

Ключ localStorage — `minimum.v2`. Зеркало — IndexedDB `minimum-v2`, store `kv`, ключ `state` (запись ~300 мс после изменения).

```json
{
  "schema": 1, "createdAt": "2026-09-30", "since": "2026-07-20",
  "items":  [{ "id": "uuid", "icon": "sunrise", "name": "…", "note": "…", "color": "orange",
               "beforeBed": null, "addedAt": "YYYY-MM-DD", "archivedAt": null }],
  "weekly": [{ "id": "uuid", "icon": "pulse", "name": "Тренировка", "note": "…", "color": "green",
               "perWeek": 3, "addedAt": "YYYY-MM-DD", "archivedAt": null }],
  "days": { "YYYY-MM-DD": { "plan": ["uuid"], "done": ["uuid"] } },
  "weekMarks": { "uuid": ["YYYY-MM-DD"] },
  "sleep": { "goalBed": "23:30", "goalWake": "07:30",
             "targets": [{ "from": "YYYY-MM-DD", "bed": "01:00" }],
             "nights": { "YYYY-MM-DD(утро)": { "bed": "01:00", "wake": "07:30" } } },
  "reviews": { "YYYY-MM-DD(пн)": { "closedAt": "ISO", "good": "", "bad": "", "learned": "", "notesDone": false,
               "improvement": "", "sleep": { "from": "01:00", "to": "00:30", "choice": "earlier30|earlier15|keep|later15" } } },
  "ui": { "welcomeSeen": false, "news": "v53", "lastExport": "YYYY-MM-DD|" }
}
```

`icon` — id из `icons.js` (иначе `star`), `color` — из `COLORS`: red orange yellow green mint teal blue indigo purple pink brown gray (иначе `blue`).
`since` («в системе с»): новый телефон — день посева; «Сбросить к шаблону» сохраняет прежний.
Шаблон нового телефона (и «Сбросить к шаблону») — базовый (v56), по ходу дня: «Стакан воды», «Зарядка», «План на завтра»,
«Телефон на кухню» (за 30 минут до отбоя), «Чтение»; подписи без рода («после подъёма», не «как встал»), недельных счётчиков
нет — свои пункты человек добавляет сам. Личный список БАО — не шаблон.

Друзья — отдельно от состояния, экспорт их не трогает: `minimum.cloud` (+ та же запись в зеркале IndexedDB) —
`{ v, secret, id, code, name, hidden: [id пунктов], sleep, onepct, sent }`; `minimum.cloud-cache` — последний ответ сервера
`{ at, now, friends, incoming, outgoing }`, **только в IndexedDB** (localStorage общий со всеми PWA домена — его место для отметок).
Префикс `minimum.` с точкой — `purgeLegacy()` (`minimum:`) их не трогает. Друзья включены — кэш друзей ждём до первого кадра не дольше 150 мс (`FIRST_WAIT`: гонка на «Сегодня» сразу на месте,
минимум не съезжает), не успел — друзья появятся после первого кадра; IndexedDB ждём не дольше 1,5 с.
`normalize()` (он же `migrate()`): битые поля → значения по умолчанию, неизвестные выбрасываются. Новая версия схемы —
`schema` + ветка в `migrate()`, только по решению владельца. Правки пунктов не переписывают прошлое: прошлые дни живут
своими снимками плана, название показывается по id. Пункты не удаляются — только `archivedAt`.

## Правила расчёта (`domain.js`)

- **Логический день:** граница 04:00 местного (константа). Арифметика дат — календарная по `YYYY-MM-DD` через `Date.UTC`; переходы времени не сдвигают дни. Открытое приложение перерисовывается на границе (таймер + `visibilitychange`).
- **Неделя** — пн–вс.
- **План дня:** `days[D].plan` — снимок активных пунктов. Сегодня снимок живой. Вчера можно доотмечать до конца сегодняшнего логического дня (нет записи — создаётся с активными пунктами). Раньше вчера — заморожено. День без записи для статистики восстанавливается по `addedAt`/`archivedAt`.
- **Статус:** `closed` — план не пуст и весь в `done`; `pending` — сегодня и не закрыт; `miss` — прошедший день ≥ `createdAt` не закрыт или без записи; `none` — до `createdAt`, пустой план, или незакрытый день посева.
- **Серия:** назад от сегодня (если закрыт) или от вчера: `closed` → +1 и сброс пропусков; `miss` → пропуск, на втором подряд — стоп; `none` — мимо. З З П З → 3; З П П З → 1. **Рекорд** — максимум тем же правилом.
- **Недельный счётчик:** `weekMarks[id]` — даты, не больше одной в день; счёт недели — с пн по вс.
- **Сон:** ночь — под датой утра. `norm(HH:MM)` = минуты, при часе < 12 плюс 1440. `targetFor(date)` — последний `targets` с `from ≤ date`. «В цель» — `bed` есть и `norm(bed) ≤ norm(targetFor)`. Длительность — `(wake + 1440) − norm(bed)`. Дедлайн пункта с `beforeBed` — `шаг − beforeBed` через полночь.
- **Предложение на итогах недели W:** утра E — с max(пн W, `createdAt` + 1) по min(вс W, сегодня); r = K / |E|. r ≥ 0.7 → рекомендовано «−30» (ещё «−15», «Оставить»); 0.4 ≤ r < 0.7 → «Оставить» (ещё «−15»); r < 0.4 → «Оставить» (ещё «+15»); |E| = 0 → только «Оставить». Не раньше цели отбоя, не позже 03:00; одинаковое время — одна кнопка. Выбор обязателен; новый шаг — в `targets` с `from` = завтра. Ручная правка шага — так же, но если этой ночью новый отбой уже прошёл — со следующей ночи (`stepFrom`: задним числом «позже шага» не ставим).
- **Сон в часах** (`sleepFor(bed, wake)`): Настройки → «Сон» показывают «сон сейчас» (шаг → подъём) и «цель» в часах, меняются степпером по 15 минут: «сейчас» — от отбоя 03:00 до цели, цель — от «сейчас» до 10 ч; «Сразу на цель» ставит шаг на цель. Подъём меняется — часы сна те же: цель отбоя и шаг сдвигаются на ту же разницу (`setWake`). Днём герой пишет «Отбой 00:45 · 6 ч 45 мин сна», варианты шага на итогах недели — тоже с часами сна.
- **Итоги:** в воскресенье — баннер этой недели; пн–сб — баннер незакрытой прошлой. Строка «1% недели» — всю неделю после закрытой.
- **Круглые даты серии** (`MILESTONES`): 3, 7, 14, 21, 30, 50, 66, 100, дальше каждые 50 — подпись героя «Серия N дней» и праздник крупнее.
- **Отсчёт до отбоя** (`untilMin`): вечер — с 18:00 до 04:00; минуты от «сейчас» до шага и до дедлайна пункта с `beforeBed`; ночное время — после вечернего (`nowNorm`).
- **Детали пункта** (`itemStats`): ежедневный — серия и рекорд по правилу «не пропускай дважды» (`itemStatus`), доля за 28 дней по дням, где он был в плане, клетки 6 недель пн–вс (`done|miss|pending|off|future`); недельный — счёт этой недели, 8 недель, недели в цель среди завершённых.

## Друзья (`share.js`, `cloud.js`, `supabase/friends.sql`)

- **Личность — секрет устройства:** 32 случайных байта (base64url) в `minimum.cloud`; на сервере — только `sha256`. Ни почты, ни паролей, ни сессий. Секрет пишется на диск **до** запроса `minimum_join`: повтор после потерянного ответа возвращает тот же профиль. Один телефон — один профиль; переустановка — новый код (друзей добавить заново).
- **Код** — 5 символов из `23456789ABCDEFGHJKLMNPQRSTUVWXYZ` (без 0/O/1/I); ввод чистится (`k7m-2p` → `K7M2P`, кириллица-двойник русской раскладки `к7м2р` → `K7M2P` — и в `cloud.js`, и в SQL). Дружба — только взаимно: запрос по коду → «Принять» через подтверждение с **кодом** запросившего (имя он пишет сам — назваться «Сашей» может любой, у кого есть твой код); встречные запросы — сразу друзья. Имя адресата до согласия не раскрывается.
- **Снимок** (`shareOf`) — состояние v2 в том же формате (читается `normalize`), id пунктов сжаты до номеров, дни — `[номер плана, флаги]`, история — окно 3 года (`WINDOW_DAYS`, ≈ 40 КБ), ночи — 42 последних утра, неделя закрыта — только день, `meta: { v, tz, day, hidden, sleep, onepct }`. **Никогда не уходят:** «получилось / не получилось / научился», Notes, uuid, `ui`. Скрытый пункт уходит «Личным пунктом» (серый, без подписи и значка) — отметки остаются, чтобы «3 из 9» у друга совпадало. Сон и «1% недели» — по переключателю; сон скрыт — и «до 00:30» у пунктов не уходит. Видимость пункта — и в «Что видят друзья» (с убранными), и переключателем «Видно друзьям» в листе пункта: новый личный пункт скрыт уже в первом снимке. Текст чистится (`clean`): без управляющих символов и половинок эмодзи — иначе Postgres не примет jsonb.
- **Чужой снимок — недоверенные данные:** только через `readShare` → `normalize`; текст — только текстовыми узлами. День друга — логический день **в его поясе** (`logicalDateIn`, граница 04:00), не раньше дня снимка (а день снимка «из будущего» дальше чем на 2 дня — не верим). Окно 3 года, не больше 60 пунктов и 20 счётчиков, id вне списка пунктов выброшены — мусорный снимок не подвесит вкладку. Всё считается теми же функциями `domain.js`, что и своё: друг видит ровно то, что показал бы твой телефон («Я → так тебя видят друзья» — тот же путь).
- **Когда уходит снимок:** через 2,5 с после изменения (отметки подряд — одним запросом), при уходе в фон (сразу, `keepalive`, если меньше 60 КБ), при открытии приложения и вкладки. Неизменённый снимок (отпечаток `sent`) не шлётся. Друзья — при запуске, возвращении и переходе на «Друзья» или «Сегодня» (не чаще раза в 8 с) и раз в минуту, пока открыта вкладка «Друзья» или гонка на «Сегодня» (есть хоть один друг со снимком).
- **Ошибки:** нет сети — «Нет связи с сервером», друзья из кэша; 5xx и спящий проект — «Сервер не отвечает»; 401/403/404 — «Сервер не настроен»; сервер отверг сам снимок (4xx) — друзья всё равно обновляются, тот же снимок больше не шлётся, на вкладке — предупреждение; `unknown_secret` — профиль забыт, **секрет, имя и видимость остаются**: «Включить заново» вернёт тот же профиль, если он на сервере есть. Выключить друзей без связи нельзя — профиль на сервере остался бы. Ответ сервера, пришедший, когда открыт уже другой лист, этот лист не закрывает — только подсказка.
- **Сервер:** таблицы в закрытой схеме `minimum` (у anon/authenticated нет даже USAGE, RLS без политик — вторая линия); снаружи только `public.minimum_join/publish/sync/request/accept/remove/rename/leave` (`security definer`, `search_path = ''`, явные GRANT — Supabase больше не открывает новые объекты сам). Пределы: 20 попыток «добавить» в час на человека, 30 регистраций в час на сервер, не больше 500 профилей (профиль без связей, молчавший 14 дней, освобождает место при следующей регистрации), снимок до 128 КБ (`jsonb::text`), 50 своих связей (исходящие + друзья), у адресата — не больше 20 ждущих запросов. Итого база не перерастёт ~64 МБ при пределе бесплатного проекта 500 МБ. Ключ — publishable (`sb_publishable_…`) в заголовке `apikey`, без `Authorization`. Бесплатный проект засыпает после недели тишины — будит владелец в панели Supabase.
- **Гонка недели** (v56, решение владельца) — единственное соревнование. Счёт (`weekScore`) — закрытые дни + ночи в цель с
  понедельника по сегодня, максимум 14: каждый идёт против своего минимума и своего шага отбоя, поэтому честно при разных
  пунктах. Неполный день не считается (как в серии), недельные счётчики не считаются (у друга их может не быть), скрытый
  сон — ночи не в счёт. «Ты» считается из своего снимка — место то же, что видят друзья. Места (`ranked`): больше счёт —
  выше, равный счёт — общее место (1, 1, 3), порядок при равном — по закрытым дням. Итоги — в понедельник (воскресенье ещё
  можно доотметить до конца понедельника), со вторника — новая гонка. Очков, уровней, званий и истории побед нет; список
  на вкладке «Друзья» — по-прежнему в порядке добавления.
- **Известное ограничение:** секрет лежит в localStorage домена `xbaox.github.io`, общего с другими PWA владельца — любой скрипт любой из них может его прочитать. Свой домен для «Минимума» закрыл бы это; пока не делаем.

## Переход с v1 (v50) — не ломать

- При каждом старте `purgeLegacy()`: удалить ключи localStorage с префиксом `minimum:` и базу IndexedDB `minimum`. **Старые ключи и базу не возвращать никогда**, импорт старого файла — отказ.
- Воркер понимает протокол старой страницы: `{type:'version'}` + порт → `{version}` в порт; `{type:'skipWaiting'}` → `self.skipWaiting()`. Формат `VERSION` строго `minimum-vN` (страница v50 читает `^minimum-(v\d+)$`).
- `install` кладёт `ASSETS` с `cache: 'reload'` и ждёт (без автоматического `skipWaiting`). `activate` удаляет **только** кэши с префиксом `minimum-`, кроме текущего, и делает `clients.claim()`. **Чужие кэши не трогать** — Cache Storage общий на домен.
- Страница: регистрация `./sw.js` с `updateViaCache: 'none'`; есть ожидающий воркер при живом контроллере → полоса «Доступна новая версия · Обновить»; перезагрузка после `controllerchange` — только если владелец нажал. Проверка — при запуске, при возвращении из фона (не чаще раза в 10 минут) и кнопкой в Настройках.

## Интерфейс — неизменяемые правила

- iOS Safari standalone; основной экран 428×926, проверять и 390×844. `viewport-fit=cover`, safe-area, `100dvh`, цели ≥ 44 px (чипы 36 px — с невидимой зоной касания), поля ≥ 16 px, строки пунктов ≥ 56 px, `touch-action: manipulation`, свой `:active`.
- **Дизайн утверждён владельцем** — «натив + кольца + закат». Эталон v3 — `C:\Users\zabao\Projects\minimum-v3-kit\reference\*.png` (статика) и `frames\*.png` (покадрово); статичные экраны v52 — `C:\Users\zabao\Projects\minimum-design-kit\reference\*.png`. Отступать от эталона — только по слову владельца.
- Язык дизайна: сгруппированные списки iOS (карточки 14 px на фоне, разделители с отступом до текста), плитка 30×30 с белым контурным значком, пустой кружок → градиентная галочка. Три кольца героя: снаружи — минимум дня (закат), в середине — сон «в цель» за неделю (сине-голубой), внутри — первый недельный счётчик (зелёный; нет счётчиков — колец два). Закатный градиент — прогресс минимума, главная кнопка и герой закрытого дня (белые кольца, волна света по полосе). Эмодзи в интерфейсе нет.
- **Гонка недели** на «Сегодня» — карточка над «Минимумом» (после утренней карточки сна и баннеров), только если есть друзья с данными.
  Строка: место (у лидера — корона в закатном градиенте), мини-кольца, имя, отметки сегодня (галочка на градиенте или «k/n»),
  отбой прошлой ночи (синим — в цель, замок — сон скрыт), счёт недели; колонки ровные. Под «Ты» — «до лидера N», «впереди на N»
  или «вровень». Строк не больше четырёх и их число не скачет: первые четыре, «Ты» ниже — вместо четвёртого. Сверху справа — «ещё N дней» / «последний день». В понедельник — «Итоги гонки»
  с датами прошлой недели: победитель на закатной полосе, колонки — дни и ночи, у «Ты» — «+N к прошлой», «как на прошлой» или «прошлая — N» (спад — без минуса). Закрыл день — строки
  меняются местами через FLIP. Тап по строке — лист друга (своя — «так тебя видят друзья»). Последнее место ничем не выделяется:
  ни красного, ни «проиграл». Пока гонка на экране, друзья обновляются раз в минуту.
- **Друзья** — как «Общий доступ» в Фитнесе: вкладка (4-я, только если в `cloud.js` есть адрес и ключ) с карточкой кода, запросами, строкой «Я» и друзьями (их кольца на сегодня, «k из n», огонёк серии) и «Ждут ответа». Лист друга — тот же герой (без отсчёта до отбоя), его минимум и счётчики только для чтения, неделя колец, цепь 6 недель (не нажимается), сон 14 ночей, «Изменения». Лента — без глаголов прошедшего времени (пол друга неизвестен). Входящий запрос — точка на вкладке. Разрыв дружбы и выключение — через системное подтверждение.
- Все цвета, радиусы, отступы, кегли, длительности — только токены `:root` (сторожит `tests/style.test.js`). Текст ≥ 4.5:1, белый значок на плитке и галочка на градиенте ≥ 3:1, белый текст кнопки ≥ 4.5:1 в середине градиента. Листы переопределяют токены поверхности (`.sheet { --cell: var(--cell-2) … }`).
- **Рендер (v3):** каждый рендер строит экран заново через `h()`/`svg()`, а `patch()` переносит разницу в живой DOM — узлы живут, поэтому идут CSS-переходы и не теряются фокус, прокрутка и открытый барабан. Экран не собирать через `innerHTML`/`replaceChildren`. Элементы списков — с `key`; верхние блоки экрана и строки — `data-flip`; появление — `data-enter` (`screen|sheet|alert|bar|pop`), кольца — `data-draw`, сетки — `data-stagger`, блоки ниже таб-бара — `data-reveal`, числа — `data-roll`/`data-count`.
- **Движение:** только `transform`, `opacity`, `stroke-dashoffset` колец и цвета; раскладка двигается только через FLIP (`measure` → `patch` → `flip`). Кривые — `EASE` в `dom.js` и токены `--e-*`, длительности — токены `--t-*`. Праздник закрытия дня ≤ 1,3 с, один раз и только по касанию (не при перерисовке). «Уменьшение движения»: JS-анимации выключает `motion()`, CSS — общее правило. Сторожат `tests/style.test.js` (переходы, без `@keyframes`) и запись анимаций в `tests/dom.test.js`.
- **Жесты:** тап — отметка; удержание 450 мс — детали пункта (без отметки); лист закрывается свайпом вниз за шапку или с верха содержимого, тапом мимо и «Отменой»; введённое при свайпе и тапе мимо переспрашивается. Вкладки помнят прокрутку, повторный тап — наверх. Тактильный отклик (`haptic`) — только на действие владельца, не по таймеру.
- Конфетти (`.fx`) и узел отклика (`.haptic`) живут вне `#app` — перерисовка их не трогает. Под листом и подтверждением экран и таб-бар — `inert`.
- `text-overflow: ellipsis` запрещён. Пользовательский текст — только текстовыми узлами. Число с единицей и «до» со временем — через неразрывный пробел (`\u00a0` в исходнике, не символом).
- Родной выбор времени (`<input type=time>`): пока поле в фокусе, экран не перерисовывать — значение применяется на `blur` (iOS закрывает барабан при перерисовке).
- Подтверждения — только системным листом-алертом (`showAlert`), не «нажми ещё раз».
- Тексты интерфейса — без рода: приложением пользуются друзья, пол неизвестен. «Отбой» / «Подъём», не «Лёг» / «Встал»; «Чему научила неделя?», не «Чему научился?»; подписи шаблона — «после подъёма».
- Степпер «− +» (Настройки → «Сон») — капсула как в iOS, цель касания 44 px; число над ним — `data-roll`.
- Подпись пункта — поле, растущее по тексту (одна строка, длинная переносится; Enter — готово); переносы при вставке схлопываются в `cleanFields`.
- Графики и кольца — свой SVG, без библиотек. Язык интерфейса — русский.

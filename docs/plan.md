## Что было в плане на задачу 13

- Задача 12 «Движение» — тихие функциональные анимации на CSS: заполнение круга и сегодняшней ячейки полосы при тапе, opacity-fade при смене вкладок, сворачивание карточки разбора после решения (`motionLeave`), тихое «Сохранено» при сохранении формы. Глобальный `@media (prefers-reduced-motion: reduce)` отключает всё; конечные состояния достижимы мгновенно.
- Задача 12.1 «Движение: усиление» — амплитуда движения поднята до отчётливо заметной (диапазон 180–260 мс): scale-«просадка» круга и ячейки на тап, fade экрана с вертикальным подъёмом, отчётливое схлопывание карточки разбора по высоте.
- Задача 13 «Отделка» — визуальный слой: полная дата в тексте ожидания разбора (без «сент..»), единый вес стрелок ↑↓ и тумблеров с заметным гашением граничных, гармонизация типографики через токены (типо-шкала, радиусы, ритм секций), семантический тон `--warn` для «серия прервана» (приглушённый тёплый, не алармовый).

Исходный план проекта был исчерпан на задаче 13.

## Серия «Расписание» (задачи Р1–Р2, закрыта)

Этот раздел дописан по прямому указанию архитектора — как карта серии
из трёх задач, а не как возврат файла в источники. Источником задач
по-прежнему остаются промпты архитектора, правилом для кода — CLAUDE.md;
пометка «исторический» с файла не снимается.

1. **Р1 «Конструктор расписания» — выполнена.** Блок стал записью с
   подписью, днями недели отрезками и днём ухода (схема v19). Эффективные
   дни действия — дни блока ∧ своя маска, принадлежность блоку хранится
   журналом, и прошлое считается по маскам того дня. «Настройки» →
   «Расписание»: карточки блоков, быстрое добавление действий строками,
   копия блока; «Удалить блок» заменён обратимым «Убрать блок», который
   уводит содержимое вместе с блоком. День без запланированных действий
   нейтрален для серии, сетка разбора считает действие по дням плана.
2. **Р2 «Режимы, „Не сегодня“, свёртка» — выполнена и включила Р3.**
   Режимы расписания (схема v20): активный режим — журнал отрезков,
   блоки и действия принадлежат режиму, привычки глобальны. «Не сегодня» —
   свайп-пропуск действия, выходит из знаменателя дня; день из одних
   пропусков нейтральным не считается. Свёртка выполненных блоков.
3. **Р3** отдельной задачей не будет — вошла в Р2. Серия закрыта (релиз
   minimum-v48).

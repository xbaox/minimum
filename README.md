# Минимум

Личный PWA-трекер ежедневного минимума: несколько одинаковых каждый день пунктов, серия «не пропускай дважды»,
сон шагами к цели, итоги недели и 1% улучшения. Данные хранятся только на устройстве.

- Прод: https://xbaox.github.io/minimum/
- Без сборки: ванильный JS, ES-модули. Локально — любой статический сервер (`npx http-server . -c-1`).
- Тесты: `npm ci && npm test`.
- Правила разработки — в [CLAUDE.md](CLAUDE.md). Старая версия — тег `v1-final`.
